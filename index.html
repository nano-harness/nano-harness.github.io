03Build from source从源码开始

Every project can be cloned, built, and tested locally without a hosted release service.

所有项目都可以本地克隆、构建和测试，不依赖托管发布服务。

  1. Start with the minimal agent-loop article, then explore nano-agent.
  2. 先阅读最小 agent loop 文章，再探索 nano-agent。
  3. Add nano-symphony for issue-driven workflows and nano-cloud for distributed execution.
  4. 使用 nano-symphony 编排 issue 工作流，使用 nano-cloud 分布式执行。
  5. Use impact-analyzer, virtual-workspace, and sparse-ngram-search as independent tools or agent primitives.
  6. 将 impact-analyzer、virtual-workspace 和 sparse-ngram-search 作为独立工具或 agent 基础能力。
