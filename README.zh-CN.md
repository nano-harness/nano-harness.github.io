# nano-harness.github.io

[English](./README.md)

**nano 系列**官方网站——呈现可读的 agent loop、编排、分布式执行和实用开发工具。

- 站点地址：https://nano-harness.github.io
- Agent 基础设施：[nano-agent](https://github.com/nano-harness/nano-agent) · [nano-symphony](https://github.com/nano-harness/nano-symphony) · [nano-cloud](https://github.com/nano-harness/nano-cloud)
- 工程工具：[impact-analyzer](https://github.com/nano-harness/impact-analyzer) · [virtual-workspace](https://github.com/nano-harness/virtual-workspace) · [sparse-ngram-search](https://github.com/nano-harness/sparse-ngram-search)

本站是单个静态 `index.html`，无构建步骤，通过 GitHub Pages 从 `main` 分支部署。展示的所有项目都可以从源码构建和测试。
