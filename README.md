# nano-harness.github.io

[中文](./README.zh-CN.md)

The official landing page for the **nano series** — readable agent loops, orchestration, distributed execution, and practical developer tools.

- Live site: https://nano-harness.github.io
- Agent infrastructure: [nano-agent](https://github.com/nano-harness/nano-agent) · [nano-symphony](https://github.com/nano-harness/nano-symphony) · [nano-cloud](https://github.com/nano-harness/nano-cloud)
- Engineering tools: [impact-analyzer](https://github.com/nano-harness/impact-analyzer) · [virtual-workspace](https://github.com/nano-harness/virtual-workspace) · [sparse-ngram-search](https://github.com/nano-harness/sparse-ngram-search)

The site is a single static `index.html` with no build step, deployed via GitHub Pages from the `main` branch. All featured projects can be built and tested from source.
