# nano-harness.github.io

[中文](./README.zh-CN.md)

The official landing page for the **nano series** — minimal, readable implementations of agent loops and harness engineering.

- Live site: https://nano-harness.github.io
- Projects: [nano-symphony](https://github.com/nano-harness/nano-symphony) · [nano-agent](https://github.com/nano-harness/nano-agent) · [nano-cloud](https://github.com/nano-harness/nano-cloud)
- Companion course: [harness-101](https://github.com/albert-lv/harness-101)

The site is a single static `index.html` with no build step, deployed via GitHub Pages from the `main` branch.
